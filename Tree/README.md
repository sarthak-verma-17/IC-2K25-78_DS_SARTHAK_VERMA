# TREE

A Tree is a non-linear data structure consisting of nodes connected by edges.

## BASIC TREE REPRESENTATION

```text
          A
         / \
        B   C
       / \
      D   E
```

## TERMINOLOGY

- Root: Topmost node (A).
- Parent: Node having child nodes.
- Child: Node connected below a parent.
- Leaf: Node having no children (C, D, E).
- Edge: Connection between two nodes.

## TREE TRAVERSALS

1. Preorder (Root, Left, Right)
2. Inorder (Left, Root, Right)
3. Postorder (Left, Right, Root)

## NOTES

- Tree is a non-linear data structure.
- It has a root node.
- It contains nodes and edges.
- A leaf node has no children.
