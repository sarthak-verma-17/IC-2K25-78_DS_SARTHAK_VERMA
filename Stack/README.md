# STACK

A Stack is a linear data structure that follows the LIFO (Last In First Out) principle.

## 1. NORMAL STACK

A Normal Stack is a linear data structure in which insertion and deletion take place from the TOP.

### Operations

1. Push (Insertion)
2. Pop (Deletion)
3. Peek (Top Element)
4. Display

## 2. MULTIPLE STACK

Multiple Stack is a data structure in which two or more stacks are implemented using a single array.

### Features

- Stores multiple stacks in one array.
- Uses memory efficiently.
- Each stack has its own TOP pointer.

### Operations

1. Push
2. Pop
3. Display

## NOTES

- Stack follows LIFO principle.
- Insertion is called Push.
- Deletion is called Pop.
- TOP points to the topmost element.
- Stack can be implemented using arrays and linked lists.
