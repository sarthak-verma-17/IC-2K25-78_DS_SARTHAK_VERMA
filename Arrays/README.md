# ARRAY

An Array is a linear data structure that stores elements of the same data type in contiguous memory locations.

## 1. ONE DIMENSIONAL ARRAY (1D)

A 1D Array stores elements in a single row.

### Representation

| Index | 0 | 1 | 2 | 3 |
|:---:|:---:|:---:|:---:|:---:|
| Data | 10 | 20 | 30 | 40 |

## 2. TWO DIMENSIONAL ARRAY (2D)

A 2D Array stores elements in rows and columns.

### Representation

| | Column 0 | Column 1 | Column 2 |
|:---:|:---:|:---:|:---:|
| Row 0 | 10 | 20 | 30 |
| Row 1 | 40 | 50 | 60 |
| Row 2 | 70 | 80 | 90 |

## 3. SPARSE MATRIX

A Sparse Matrix is a matrix that contains mostly zero elements.

### Features

- Saves memory.
- Stores non-zero elements.
- Used for large matrices.

## NOTES

- Array indexing starts from 0.
- 1D Array uses one index.
- 2D Array uses rows and columns.
- Sparse Matrix contains mostly zero values.
