# LINKED LIST

A linked list is a linear data structure consisting of nodes.

Each node contains two components:

1. Info (Data stored in a node)
2. Next (Pointer storing the address of the next node)

---

## Features

- Dynamic memory allocation
- Non-contiguous memory storage
- Easy insertion and deletion
- Nodes connected using pointers

## SINGLY LINKED LIST

Each node contains:

| Info | Next |
|---|---|
| Data | Address of next node |

## DOUBLY LINKED LIST

Each node contains:

| Previous | Info | Next |
|---|---|---|
| Previous node address | Data | Next node address |

## Operations

1. Create
2. Insert
3. Delete
4. Display
5. Reverse

## NOTES

- The last node's next pointer contains NULL.
- A doubly linked list contains both previous and next pointers.
- Linked lists are stored in non-contiguous memory locations.
- Memory is allocated dynamically.
